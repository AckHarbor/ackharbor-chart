# AckHarbor™ Chart™: FHIR® R4 JSON Viewer

A free, offline viewer for FHIR R4 resources and Bundles. Paste JSON, browse the element tree, and click any element for plain-English Insights and validation tips.

**Use it online:** https://ackharbor.com/tools/fhir-viewer.html

> ⚠️ **No real patient data. Do not load PHI.** Use test or de-identified resources only. All sample data is invented.

## Features

- Element tree for any FHIR R4 resource or Bundle
- Insights for common resources and elements (Patient, Observation, Encounter and more)
- Errors and warnings for invalid JSON and common FHIR mistakes
- 20 sample resources: Patient, Encounter, Observation, MedicationRequest, Bundles, OperationOutcome, Questionnaire and more
- Runs fully offline; nothing is uploaded

## How to run

1. Clone or download this repository.
2. Open `index.html` in a modern browser.

No build step and no dependencies.
